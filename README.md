# Chess System Java

A chess system developed in Java as part of the
"Java COMPLETO Programação Orientada a Objetos + Projetos" course
by Nélio Alves.

## About the project

The goal of this project is to practice Object-Oriented Programming
concepts by implementing a chess game that runs in the terminal.

## Concepts practiced

- Object-Oriented Programming (OOP)
- Encapsulation
- Inheritance
- Polymorphism
- Exception handling
- Collections
- Matrices
- Enums
- Git and GitHub

## Features

- Chess piece movement
- Move validation
- Piece capturing
- Turn control
- Check and checkmate
- Special chess moves
